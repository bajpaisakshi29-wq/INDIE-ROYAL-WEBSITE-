INDIE ROYAL — GITHUB SITE
=========================

This repository contains the complete site assembled from the six-part delivery.
Deploy the repository root to Netlify. Keep index.html, netlify.toml, and the
entire assets/ directory together.

Files:
- index.html — the page, with most images still embedded.
- assets/img/ — 31 original images extracted byte-for-byte from index.html
  so the HTML file fits GitHub's browser upload limit.
- assets/videos/hero.mp4
- assets/videos/highlights/ — 9 videos.
- assets/videos/testimonials/ — 6 videos.
- netlify.toml — hosting configuration, including video byte-range support.

The original six ZIP parts are a separate delivery format. Their old README
says there is no assets/img/ folder; that statement does not apply to this
GitHub version. The images and videos have not been redesigned or recompressed
for this repository.
